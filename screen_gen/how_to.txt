Turns each designs/<company>/Design.md into phone-PNG screens under output/<company>/. Generation (the Azure/GPT call) happens once per company and its HTML is saved; re-runs can reuse that saved HTML to re-render PNGs without spending the model again.
bash# First run — generates every company once (needs Azure creds in .env) and saves HTML + PNGs
python3 main.py

# Re-runs — reuse saved HTML, re-render PNGs, ZERO model calls.
# Use this whenever you change rendering/device-shell/image code and just want fresh PNGs.
# Companies without saved HTML yet are the only ones that call the model.
python3 main.py --reuse-html

# Preview device frames with placeholder content — no Azure calls at all
python3 main.py --dry-run

# Restrict to one company (substring match on the folder name)
python3 main.py --only framer

# Combine: reuse everything, but force one company to regenerate by deleting its output first
rm -rf output/framer && python3 main.py --reuse-html
Notes:

--reuse-html decides by whether the HTML exists, not by whether Design.md changed. If you edit a company's Design.md and want new screens, delete that company's output/<company>/ folder (or run without --reuse-html).
A fully cached --reuse-html run needs no Azure credentials — the SDK and credential check load only when a company actually has to be generated.
Output per company lands in output/<company>/: one screen_N_*.html and screen_N_*.png per screen, plus a manifest.json.
