## Design language
- Dark, high-contrast Messenger interface using #000000 backgrounds and #FFFFFF primary text.
- Secondary text uses translucent white values, primarily #FFFFFF80, #FFFFFF59, and #FFFFFF33.
- Bright blue accents appear in #0584FE and #19A3FE.
- Online status indicators use #5AD439.
- The interface uses circular avatars, translucent search surfaces, blurred top and bottom bars, compact chat rows, and bottom navigation.
- Typography is predominantly SF Pro Text for the mobile UI, with SF Pro Display for large screen headings. Public Sans and Crimson Text also appear in extracted styles.

## Screen patterns
- Messenger chats screen: 375×812px dark mobile layout with a 108px top bar, 48px search row, 76px ad row, repeated 76px chat rows, a 106px stories and online-people strip, an 86px tab bar, and iPhone status/home-bar regions.
- Chat row: 60px circular avatar, 17px medium-weight contact name, 14px secondary preview text, and optional 16px read-state indicator.
- Stories and online people: 52px circular images or story controls inside approximately 65px-wide groups, with 12px online indicators and 13px labels.
- Top bar: “Chats” heading at 30px SF Pro Display Bold, profile image, camera action, and new-message action.
- Search: 343×36px translucent field with 10px radius, search icon, and 17px placeholder text.
- Ad row: 60px avatar and thumbnail, 17px advertiser name, 14px secondary copy, 14px action text, and an 11px ad label.
- Tab bar: three navigation groups with icons and an optional notification badge.
- Swipe actions screen: repeats the chat-list pattern and exposes right- and left-swipe action groups.
- Intro/app screen: 248×248px Messenger icon area and large “Messenger UI” heading.
- Theme header screens: 1525px-wide dark and classic theme groups with a 1px divider using #00000033.

## Notes for implementers
- Prefer #000000 as the primary mobile background and #FFFFFF for primary text.
- Use #FFFFFF80 for chat previews and other secondary text; use #FFFFFF59 for story labels.
- Use #8E8E93 for search placeholder text and search icon.
- Use #5AD439 for online indicators; online indicators are 12px circles with a #000000 3px stroke.
- Keep chat rows at 76px height with 60px circular avatars.
- Use 30px SF Pro Display Bold for the “Chats” heading.
- Use SF Pro Text Medium 17px for contact names and SF Pro Text Regular 14px for previews.
- Use a 343×36px search field with 10px radius inside a 375×48px search region.
- Apply 54.37px background blur to translucent top and bottom navigation bars.
- No spacing, component, motion, grid, or local effect variables were extracted.
