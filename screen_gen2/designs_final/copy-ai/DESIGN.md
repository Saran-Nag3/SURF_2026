# copy-ai - Design System

## Overview

- Mental-health product UI kit centered on the freud brand.
- Source includes light and dark main screens, design-system components, icon sets, dashboard/app bonus screens, onboarding/marketing pages, and purchase/thank-you pages.
- No local variable collections were found.
- Primary component families: `Frame 4180`, `www.strangehelix.bio`, `Logo`, `Frame`, `Divider`, `Icon Container Base`, `Header`, `Superego`, `Solid`, `Locked`, and `Monotone`.

## Design language

- Use a calm, supportive visual language built around Mindful Brown, Serenity Green, Empathy Orange, Gentle Purple, Zen Yellow, and Optimistic Gray.
- Typography combines Urbanist for most UI, headings, labels, and paragraphs; Roobert for selected headings and paragraph styles; and Plus Jakarta Sans for selected compact labels.
- Headings use strong weights and negative tracking. Labels use uppercase-like emphasis through positive tracking.
- Rounded surfaces are prominent: cards use `32px` or `48px` radii, pill-like controls use `1234px`, and the icon container uses a `64px` circular form.
- Use soft focus rings and a very light card shadow for interaction and elevation.

## Screen patterns

- Welcome and benefits pages use brand introduction and explanatory content.
- Getting Started uses pill-shaped brown action/content frames.
- Main app is provided in both light and dark modes.
- Design System & Components centralizes typography, colors, effects, grids, and reusable UI.
- Icon Set contains the Superego and Solid icon families.
- Bonus screens include dashboard and additional app views.
- Thank-you, full-version, and thumbnail pages support presentation and product-purchase contexts.
- Documented grids include:
  - Mobile: 4 columns, `16px` gutter
  - Desktop: 12 columns, `16px` or `24px` gutter
  - 800×600 shot: 8 columns, `16px` gutter
  - Thumbnail: 6 columns, `24px` gutter

## Notes for implementers

- Prefer semantic palette names over raw colors when implementing UI.
- Preserve the exact typography family, weight, size, line height, and tracking for named text styles.
- Use the documented component dimensions when the component is used at its extracted size.
- Do not create new spacing or radius tokens; spacing and radius variables were not defined.
- Use `24px` icons for both `Superego` and `Solid`; do not substitute unsupported icon sizes.
- Apply focus/select effects using the extracted effect colors rather than inventing new shadows.
- The source contains duplicate token names with different values; when a component specifies a semantic token, use the value explicitly documented for that component.
- No motion tokens were found.
