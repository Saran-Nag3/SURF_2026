# appsmith - Design System

## Overview

Appsmith Design System 2.0 is a component-based UI system covering actions, form controls, response messaging, content, tables, file handling, navigation, layout containers, and feature announcements.

Source coverage includes 42 Figma pages, including Link, Button, Input, Select, Segmented control, Radio, Switch, Checkbox, Search, Date Picker, Toggle, Callout, Avatar, Tab, Menu, Divider, Icon, Modal, Spinner, Tag, Text, Tooltip, Collapse, Popover, Action List, Table, Draggable List, File Picker, Toast, Banner, Progress bar, Feature Announcements, form controls, and spacing fundamentals.

No local variable collections, spacing variables, radius variables, motion variables, or grid styles were found.

## Design language

- Primary action color: `#E15615`.
- Primary action hover: `#CF4D10`.
- Primary action active/emphasis: `#CA520F`.
- Primary text and control text commonly use `#4C5664`.
- Strong headings use `#364252` or `#202939`.
- Default surfaces are `#FFFFFF`.
- Muted surfaces and hover states use `#F1F5F9`.
- Error states use `#F22B2B` and `#FFF2F2`.
- Success states use `#059669` and `#ECFDF5`.
- Warning states use `#EAA108` and `#FFFBEB`.
- Informational states use `#2D6BF4` and `#EFF6FF`.
- Controls use compact 4px-radius geometry, 14px primary UI text, and 12px supplementary/helper text.
- Focus uses a `#8BB0FA` effect.

## Notes for implementers

- Prefer semantic color roles over raw colors when implementing UI.
- Use `#E15615` for primary actions, with `#CF4D10` on hover and `#CA520F` on active/emphasis states.
- Use `#4C5664` for standard body, control, label, and icon content; use `#364252` for emphasis and selected-hover content; use `#202939` for stronger headings and tooltip surfaces.
- Use `#FFFFFF` for default surfaces and inverse action content.
- Use `#F1F5F9` for muted surfaces, menu hover, table headers, and table hover states.
- Apply 4px radius to the documented compact action and control components.
- Use the documented typography tokens rather than raw typography where a semantic role exists.
- Apply the focus effect using `#8BB0FA`.
- Preserve the documented component dimensions, padding, gaps, and 1px strokes where a fixed component specification is provided.
- Do not infer undocumented spacing, radius, motion, grid, or component states.
- The extraction is truncated after the Select specification; unspecified component dimensions and variants should not be invented.
