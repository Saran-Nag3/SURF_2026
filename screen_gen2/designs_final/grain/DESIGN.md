- Source: Figma file “Grain Website UI Kit, Saas Design Kit, SaaS Website Design Example, UI Design Inspiration (Community)”.

## Design language

- Clean, editorial SaaS marketing layout with large typographic hero sections, generous vertical sections, rounded promotional areas, product screenshots, and decorative gradients or blurred shapes.
- Light-mode surfaces primarily use white, with black text and purple accent treatments.
- Primary typography uses Inter and Poppins. Kodchasan Bold is used for the Web to Figma promotional experience.
- Desktop navigation is 1425px wide and 89px high, with a 1346px container.
- Common content widths are 1200px and 1140px.
- The main marketing page includes navigation, hero content, trust content, feature sections, calls to action, and a footer.
- The Web to Figma experience uses a dark background, large white and purple typography, rounded plugin panels, and blurred decorative effects.

## Notes for implementers

- Prioritize Inter, Poppins, and Kodchasan exactly as observed; do not substitute a different typeface when the target context matches these screens.
- Use `#000000` and `#FFFFFF` as the dominant text and surface colors, with `#8243EA`, `#EBD9FF`, and `#F2EBFF` for the purple accent system.
- Preserve the wide desktop composition: use `1200px` and `1140px` content widths where applicable.
- Use rounded sections selectively. The main marketing page uses `3px` section radii, while prominent promotional areas use `40px` or larger.
- Keep feature sections vertically spacious; the source shows a `100px` gap between repeated feature blocks.
- Treat decorative shapes, images, and gradients as visual support rather than reusable component definitions.
- Do not infer unextracted component states, spacing variables, radius variables, motion behavior, or local style names.
