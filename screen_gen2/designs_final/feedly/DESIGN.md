# feedly - Design System

## Overview

- Feedly website UI kit and landing-page design reference containing a desktop marketing page, plugin-promotion screens, Figma plugin interfaces, and imported website previews.
- Primary marketing screen: 1425px wide, with a white header, white main content area, logo section, and footer.
- The extraction contains no local variables, text styles, spacing tokens, radius tokens, motion tokens, effect styles, or component sets.

## Design language

- Clean, high-contrast interface language built around white surfaces, black typography, gray interface elements, and purple accent treatments.
- Marketing and promotional compositions use large display typography, centered layouts, rounded pill-shaped calls to action, and decorative blurred purple forms.
- Poppins is common in the marketing UI; Inter is common in interface and plugin UI; Kodchasan Bold is used for expressive promotional headlines and calls to action.
- Plugin surfaces use white cards with thin dividers, compact navigation, rounded corners, and purple accent emphasis.
- A 16×16 centered icon grid is present: 1 column, 1 row, 16px section size, 0px gutter.

## Notes for implementers

- Treat the listed typography values as observed source styles rather than a normalized token scale.
- Use `#8243EA` as the primary accent and reserve `#EBD9FF` and `#F2EBFF` for pale purple treatments.
- Use `#000000` for primary dark content, `#333333` and `#757575` for secondary content, and `#D9D9D9` or `#EAECF0` for separators and neutral borders.
- Preserve the contrast between white plugin cards and dark promotional compositions.
- Use large Kodchasan Bold display text for expressive marketing statements and CTAs.
- Use Inter for plugin and utility UI; use Poppins for common marketing and website text.
- Repeated CTA geometry is pill-shaped, with observed radii of `100px` and `214.17px`.
- Prefer centered hero compositions, rounded preview cards, thin dividers, and layered blurred purple decoration when recreating the promotional screens.
- Do not assume component variants, spacing tokens, radius tokens, or motion behavior beyond the values explicitly observed here.
