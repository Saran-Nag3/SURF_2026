# shopify - Design System

## Overview

A UIKit page containing an introductory marketing screen and dark before/after-generation showcase screens. The source has no local variables, styles, or component sets. Visual language combines neutral black and white interfaces with blue and green accents in the documented screens, plus Inter and Manrope typography.

## Design language

- Use a predominantly neutral palette built from near-black surfaces and white or near-white content.
- Intro content uses large display headings, explanatory text, and a prominent filled call-to-action.
- Showcase screens use dark canvases, high-contrast white labels, dense generated UI, image-based content, and compact controls.
- Typography is primarily Inter for generated UI and Manrope for introductory marketing content.
- Layouts use generous outer padding and large vertical gaps on presentation screens.
- Intro content is vertically structured with repeated heading-and-description groups.
- Generated layouts are organized into wide document canvases with stacked blocks, cards, controls, tags, icons, and image regions.

## Screen patterns

- **Intro:** Fixed 1333×3547px white presentation frame with 160px outer padding and 88px vertical section gaps. Starts with a 140×140px image beside a large title. Uses blue headings, dark supporting text, repeated capability statements, and a 348×104px filled call-to-action with 16px radius.
- **Before generation:** Fixed 12239.72×3547px dark presentation frame with 160px outer padding, 120px vertical gap, a large 80px screen title, a 1px border, and a wide decorative image/shapes region.
- **After generation:** Fixed 17393×3547px dark presentation frame with 160px outer padding, 120px vertical gap, a large 80px screen title, a 1px green border, and a generated-design area containing multiple 1920×1320px document canvases.
- **Generated document canvases:** Wide fixed layouts with image backgrounds, stacked blocks, navigation or input regions, controls, icons, tags, avatars, cards, order summaries, customer details, and image regions.
- **Generated UI density:** Compact icons generally range from 15px to 22px; larger icon or avatar regions include 45px dimensions. Cards and content regions use radii from 4px through 22px.

## Notes for implementers

- Do not assume local design tokens exist; the extraction found no variables or local styles.
- Prefer Inter for generated-product UI and Manrope for the introductory presentation content.
- Preserve the strong contrast between near-black surfaces and white or near-white text.
- Use the observed spacing values rather than introducing a new spacing scale.
- Use only the observed radius values; do not add unsupported radii.
- Treat the named generated frames as screen patterns, not reusable component definitions: the source reports no component families or component specs.
- Image fills are present throughout the generated screens, but their source images are hash references and are not replaceable color tokens.
