# klarna - Design System

## Overview

- Source page: All pages (2): Welcome, Klarna website.
- The extraction contains a Welcome presentation with introductory guidance and promotional content, plus a Klarna website mockup.
- The website mockup includes a wide header, navigation-style content, hero and content sections, image-led areas, and multiple background treatments.
- No local variable collections, component families, spacing variables, radius variables, motion variables, or grid styles were found.

## Design language

- Primary UI typography uses Roboto with regular, medium, semibold, and bold weights.
- Inter is used for large presentation headings and supporting text in the Welcome screens.
- Lato is used for presentation branding and promotional headings.
- The visual language combines dark violet surfaces, white content areas, pale gray and pastel backgrounds, bright blue accents, and lavender/purple presentation accents.
- Large, bold headings are paired with compact links, buttons, and supporting copy.
- Presentation content uses rounded cards, image thumbnails, decorative shapes, and soft blur/shadow treatments.
- Website layouts use broad horizontal containers and generous section padding.

## Notes for implementers

- Prefer Roboto for website UI, links, buttons, inputs, and semantic headings.
- Use Inter for the large Welcome presentation headline and supporting copy where presentation typography is required.
- Use Lato for the presentation brand label and promotional showcase headings.
- Prioritize `#0B051D`, `#FFFFFF`, `#6666990D`, `#96959F`, and `#FCD3D3` according to the reported usage ranking.
- Keep website sections spacious, using 120px horizontal padding where the source specifies it.
- Use large, bold headings with explicit line heights; do not substitute arbitrary type sizes.
- Use rounded containers only with observed radii such as 9px, 12px, 24.11px, 26px, or 28.62px.
- No reusable component geometry was extracted. Build reusable components only from the documented visual patterns, without assuming undocumented variants.
- The source contains image fills and decorative vectors, but their image assets and vector geometry are not defined as reusable components.
