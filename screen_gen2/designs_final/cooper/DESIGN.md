# cooper - Design System

## Overview

- Source: Iridescence Design System (Community)
- Source pages include overview, about, device, colors, typography, icons, buttons, checkboxes, chips, progress, radio buttons, text inputs, toggles, and extras.
- The system is built around Roboto typography, Font Awesome icons, dark charcoal/black surfaces, white content, and bright cyan, green, indigo, magenta, orange, red, violet, and yellow accents.
- No local variable collections, grid styles, motion tokens, or effect styles were found.

## Design language

- Dark foundation:
  - Black: `#000000`
  - Charcoal: `#121212`
  - White: `#FFFFFF`
- Cyan is the primary theme color:
  - Theme: `#00F5F5`
  - Primary cyan token: `#00F5F5`
- Accent colors are vivid and iridescent: green, yellow, orange, red, magenta, violet, indigo, and cyan.
- Components commonly use 8px corner radii, 16px internal padding, and 8px or 16px gaps.
- Typography uses Roboto Regular, Medium, and Bold. Icons use Font Awesome 6 Free or Pro weights.
- Common component states include default, disabled, hovered, pressed, focused, dragged, selected, unselected, error, success, on, and off.

## Notes for implementers

- Use only the named component families and their listed variants.
- Preserve the exact supplied dimensions, padding, gaps, radii, stroke widths, and alignments.
- Prefer usage-ranked tokens for common UI:
  - `#FFFFFF`
  - `#888888`
  - `#121212`
  - `#000000`
  - `#10EF99`
  - `#AD93FB`
  - `#FF758C`
  - `#00F5F5`
  - `#66A3FF`
- Use `#00F5F5` for the theme token and primary cyan treatment.
- Do not create a spacing scale, radius scale, elevation system, or motion system beyond the concrete values listed here.
- Use Roboto for interface text and Font Awesome for iconography.
- The source contains raw unstyled Roboto Regular at 33.14px and raw Font Awesome 6 Pro styles at 16px; use these only where matching the `iridescence`, device, or status component specifications.
