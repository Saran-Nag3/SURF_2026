# lenovo - Design System

## Overview

Cake is Lenovo’s design system covering foundations, controls, data display, feedback, navigation, iconography, and AI experiences. Source pages include Color, Color tokens, Iconography, Language & grammar, Typography, Accordion, Alert, Avatar, Badge, Breadcrumb, Button, Checkbox, Chip, Data Table, Date Picker, Dropdown, Link, Loading, Text Area, Text Field, Modal, Menu, Radio, Scrollbar, Search Bar, Segmented Control, Slider, Tab, Toggle, Tooltip, AI Icon + Identity, AI Chat, AI Response, AI FAB, AI Text Field, AI Disclaimer, and AI Placement.

No local variable collections, spacing variables, radius variables, motion variables, or local grid styles were found.

## Design language

- Primary typeface: Segoe UI.
- Primary text weights: Regular (400) and Semibold (600).
- Supporting typeface: Roboto Medium (500) for `cake.light/Typography/Subtitle 2`.
- Controls commonly use 40px height and 100px radius.
- Common icon size is 24x24px.
- Primary interactive color: #1D4ED8.
- Secondary controls use #E2E8F0 with #64748B borders.
- Destructive controls use #B91C1C.
- Surfaces commonly use #FFFFFF, #F8FAFC, or #FAFAFA.
- AI identity uses purple-to-blue gradients.

## Notes for implementers

- Use only the documented component families and their listed variants.
- Prefer the named type tokens over raw typography values where applicable.
- Use #1D4ED8 for primary controls, #E2E8F0 with #64748B for secondary controls, and #B91C1C for destructive controls.
- Preserve the documented 24x24px icon size unless a component explicitly specifies 32px, 40px, or 48px.
- Preserve component-specific dimensions, padding, gaps, strokes, fills, radii, and elevation effects.
- Do not infer spacing, radius, motion, or grid tokens beyond the explicit component values because no corresponding variable collections were found.
- Do not use archived components or patterns.
