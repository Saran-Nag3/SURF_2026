## Overview

- Source: Figma file `IKEA UI Screens (Community)`, page `UIKit`.

## Design language

- The presentation uses high-contrast light and dark surfaces.
- Introductory content uses blue `#4499F8` for headings and call-to-action surfaces, dark purple `#1F1736` for supporting copy, and white `#FFFFFF` for the intro surface.
- Generated-design presentation areas use dark neutral backgrounds with white headings and light divider strokes.
- Typography is predominantly Inter Regular across UI components, with Manrope used for introductory presentation headings and supporting copy.
- Buttons are compact, pill-shaped controls with 19–20px radii.
- Tags use compact 2px-radius rectangles.
- Component examples are arranged in large padded containers with repeated 84px internal padding and 20px or 80px inter-section gaps.

## Notes for implementers

- Prefer the extracted component family names exactly when selecting or mapping components.
- Do not introduce new local tokens; the source contains no variables or local style definitions.
- Use the observed Inter sizes for UI components and reserve the observed Manrope styles for introductory presentation content.
- Preserve the distinction between blue introductory headings and dark presentation surfaces.
- Preserve the compact 19–20px button radii and 2px tag radii.
- Image-filled controls should remain image-backed rather than being replaced with invented color values.
- No usage counts were provided for local style references; component usage must be inferred from the extracted specs and screen patterns.
