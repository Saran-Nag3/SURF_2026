# figma - Design System

## Overview

- Figma file: Mobile Web Browser UI Frames (Community)
- Figma page: Clay
- Primary subject: mobile browser UI frames for iOS Chrome, iOS Safari, and Android Chrome.
- Screens include a 1280×800 presentation canvas and a “Get more components” marketing-style screen.
- No local variables, text styles, spacing variables, radius variables, motion tokens, components, or component sets were found.

## Design language

- Platform-specific browser chrome with separate iOS and Android treatments.
- iOS variants include Safari and Chrome, each with light and dark modes.
- Light browser chrome uses #FFFFFF with light gray address fields and active blue controls.
- Dark browser chrome uses dark gray bars and lighter text/icon treatments.
- Presentation visuals use large display typography, centered compositions, decorative sparkles, dots, glows, gradients, and blurred shapes.
- Frosted-glass surfaces are used for browser bars and address-bar backgrounds.
- Browser controls use compact icon labels and horizontally distributed navigation actions.
- A 16×16 centered icon grid is defined with 1 column, 1 row, 16px sections, and 0px gutters.

## Screen patterns

- **Clay / 1280×800:** Presentation canvas containing iOS Chrome dark/light frames, iOS Safari dark/light frames, decorative purple/white visual elements, a large “Browser Mobile Frames” title, and a Figma-themed square.
- **Clay / Get more components:** Dark presentation screen with large “Design inspirations, meet Figma” typography, supporting copy, background pattern imagery, decorative dots, sparkles, and purple blurred glows.
- **iOS Chrome frame:** Status bar at the top, rounded address field below, and a tab bar at the bottom. Light mode uses dark text/icons; dark mode uses white text/icons.
- **iOS Safari frame:** Address/search field near the top and a bottom tab bar containing back, forward, share, bookmarks, and new-tab controls. Active controls use #007AFF or #0084FF; inactive navigation controls use #A3A3A3.
- **Android Chrome tokens:** Dark gray bars, light address-field backgrounds, separator lines, secondary text, and system icons are defined, but no complete Android screen geometry was extracted.

## Notes for implementers

- Treat iOS Chrome, iOS Safari, light mode, and dark mode as separate browser-chrome patterns.
- Use SF Pro Text for iOS interface text and icons, Inter for supporting interface or presentation text, Kodchasan Bold for large presentation headlines, and Product Sans Regular where explicitly required.
- Preserve the distinction between #007AFF for iOS active controls and #0084FF for dark-mode active controls.
- Use #A3A3A3 for inactive iOS navigation controls.
- Use rounded address fields and bottom tab bars; the exact observed radii differ by platform, browser, and scale.
- Use frosted-glass blur on translucent browser bars where the implementation supports it.
- Do not infer missing component APIs, spacing variables, radius variables, motion behavior, or text styles; they were not extracted.
- Avoid reproducing decorative presentation artwork as reusable UI components unless separately specified.
