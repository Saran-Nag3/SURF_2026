## Design language

- Use dark blue and white as the dominant brand colors.
- Use black and dark navy text for high-contrast content.
- Use accent blues for interactive or emphasized elements.
- Use Nunito for headings and prominent display text.
- Use Roboto for body copy, labels, buttons, author information, and profile names.
- Use Goldman Sans for the alternate body and heading styles.
- Use Roboto Mono for documentation and item labels.
- The desktop grid is 12 columns with a 4px grid, 72px section spacing, and 24px gutters, aligned center.
- The document grid uses 6 columns, 223px section spacing, and a 1px gutter, aligned stretch.
