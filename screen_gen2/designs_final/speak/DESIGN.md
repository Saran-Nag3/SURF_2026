## Design language

- Friendly educational mobile UI using rounded controls, colorful semantic states, illustrated/course-card surfaces, and conversational learning flows.
- Primary typeface system is Nunito, with additional Inter and Mulish styles in the extracted style library.
- Core semantic colors include blue, orange, pink, cyan, green, yellow, red, neutral darks, and pale supporting tones.
- Components commonly use fixed mobile-oriented dimensions such as 320px, 360px, and 58px circular controls.
- Chat and learning interactions use pressed, active, selected, success, wrong, disabled, light, and dark states.

## Notes for implementers

- Prefer Nunito for the primary product UI; use the named Inter and Mulish styles only where their extracted tokens specify them.
- Use the semantic primary blue #2563EB for main actions and #E3EDFF for subtle primary surfaces.
- Use #FE9519 or #FF991F for secondary/orange course emphasis.
- Preserve the extracted state vocabulary: default, hover, focus, active, pressed, selected, disabled, success, wrong, error, light, dark, filled, tonal, outline, and underline.
- Use the exact fixed component dimensions where a component is specified; do not resize controls arbitrarily.
- Use #FFFFFF for primary light surfaces and #000000 or #263038 for dark text/surfaces according to the component’s semantic role.
- Use translucent overlays and the named shadow styles rather than introducing new effects.
- No spacing, radius, or motion variables were extracted; use the observed component-level values documented above.
- The extraction contains multiple raw typography families and colors. For new product UI, prioritize named typography tokens and deduplicated semantic colors over unstyled raw values.
