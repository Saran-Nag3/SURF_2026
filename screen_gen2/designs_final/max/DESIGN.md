# max - Design System

## Overview

Apple-inspired product landing-page system extracted from Figma Page 1.

- Primary canvas: 1425px wide.
- Primary experience: long-form product storytelling with full-width hero sections, large product media, centered copy, galleries, navigation, and footer content.
- Extracted screens:
  - Apple Landing Page Design: 10,267.1px tall.

- No local variable collections or text styles were found.
- No component sets or component geometry were found.

## Design language

- Minimal, premium, product-focused visual language.
- Strong contrast between black product sections and light neutral sections.
- Large Inter SemiBold headlines paired with smaller Inter Regular body copy.
- Poppins Regular appears in a limited set of small text styles.
- Full-bleed media and video areas are central to the layout.
- Navigation uses compact 44px-high bars.
- Content is organized into long, vertically stacked sections with large product imagery.
- Use rounded cards selectively; most hero and media sections use square edges.

## Notes for implementers

- Do not introduce a component library or inferred component families; the extraction contains no components.
- Prefer full-width 1425px sections for desktop compositions.
- Keep product media visually dominant and pair it with compact, centered copy wrappers.
- Use #000000 and #FFFFFF for the strongest hero contrast.
- Use #F5F5F7, #EAECF0, and #F2F4F7 for light neutral surfaces.
- Use #0066CC for links and action accents.
- Use translucent black and white colors for navigation overlays and secondary content instead of adding new opacity values.
- Preserve the 44px global navigation and 52px local navigation heights.
- Use the 16px icon grid where icon sizing is required.
- Keep large cards at 28px radius and compact pill controls at 32px radius.
- Avoid adding gradients, effects, colors, spacing variables, or typography styles not explicitly present in this document.
