# tiffany - Design System

## Overview

Unofficial Tiffany & Co. community design system extraction from the Figma file “The Blue Box Design System from Tiffany & Co. (Unofficial) (Community).” The source covers five pages: Cover, Introduction, Style, Components, and Assets.

The system defines turquoise-led ecommerce UI with Inter for interface typography and Abhaya Libre for editorial and product-oriented typography. Components are primarily documented at fixed desktop dimensions, with explicit state and variant properties.

## Design language

- Use turquoise as the primary brand accent: `#81D8D0`.
- Use white surfaces and black primary actions.
- Use Inter for navigation, labels, buttons, forms, and body copy.
- Use Abhaya Libre for editorial headings and selected product content.
- Use restrained layouts with white or light-gray backgrounds.
- Use bordered cards, fixed-width controls, image-led banners, product cards, carousels, collapsible sections, and ecommerce forms.
- Buttons and controls use explicit state variants such as Initial, Hover, Clicked, Opened, Closed, Normal State, and Error State.
- No local variables, spacing styles, radius styles, motion variables, effect styles, or grid styles were found.
