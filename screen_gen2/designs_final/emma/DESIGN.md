# emma - Design System

## Overview

- UVU Design System Community extraction from the Figma file “UVU Design System (Community)”.
- Source scope: All pages (9), including Start Here, Examples, Foundations, Layout, Styles, Icon, and Components.
- No local variable collections were found.
- The system combines UVU green branding, Rajdhani display typography, Lato body typography, geometric patterns, structured card layouts, and 12-column desktop grids.
- Desktop layouts use 12 columns with 70px sections and 30px gutters. Mobile layouts use 6 columns with 32.83px sections and 5px gutters.

## Design language

- Brand identity is centered on Primary Green `#275D38`, Forest Green `#00843D`, Fern Green `#78BE20`, and Clover `#4BA23F`.
- Use Rajdhani for prominent headings, navigation, section titles, and display text. Use Lato for body copy and card content.
- Headings frequently use uppercase styling, especially Rajdhani headings between 18px and 48px.
- Layouts use geometric decorative assets: circles, squares, zigzags, stairs, checkered patterns, stripes, polka dots, and Utah-themed patterns.
- Content is organized through templates, banners, cards, resource links, testimonials, department sections, and event structures.
- Desktop page structures are centered and use fixed-width template compositions such as 1170px and 1440px.
- Use white backgrounds and high-contrast black or green text where source components specify white, black, or green fills.

## Screen patterns

- Department and university pages use centered desktop content with the 12-column UVU layouts.
- Mobile pages use the 6-column UVU Mobile Layout with 5px gutters and stretch alignment.
- News screens use News Template variants at `1440px` wide, with either `40px` vertical padding and no gap or `60px` bottom padding with a `60px` gap.
- Faculty spotlight screens use `1170px` wide vertical templates, with either `40px` vertical padding and no gap or `60px` bottom padding with a `40px` gap.
- About sections use horizontal `1170px` or `1172px` layouts with a `30px` gap.
- Program and degree screens combine Main Degree Section, Degree, Program Template, program links, resource sections, salaries, career outlook, testimonials, and department content.
- News and event screens combine News Story, News Banner, Event Card, event-list-item, Card: Event, and numbered event-card variants.
- Resource screens use Department Resource Card, University Resource Card, Extra Resources, PDF Links, Program Links, and Portfolio Links.
- Header and footer patterns differ by viewport through GlobalHeaderNav, Desktop Contact, Mobile Contact, Mobile Nav Bar, Mobile Footer, FooterDept, Footer Links, and Footer Socials.
- Decorative assets are used as patterned backgrounds, geometric accents, icon backgrounds, Utah branding, and informational graphics around content sections.

## Notes for implementers

- Prefer the concrete named components and styles above instead of creating new component families.
- Use `#275D38` as the most-used branded green, followed by `#00843D`, `#78BE20`, and `#4BA23F` where the selected component or pattern calls for green.
- Use `#000000` and `#FFFFFF` as the highest-usage neutral colors. Use `#F9F9F9`, `#EFEFEF`, `#E8E8E8`, `#DDDDDD`, and `#D9D9D9` for the extracted light neutral surfaces and separators.
- Use Rajdhani for display and heading hierarchy; use Lato for most body and card text. Preserve uppercase styling where the named typography style specifies it.
- Do not infer spacing tokens or corner radii; neither spacing variables nor radius variables were found.
- Use the extracted grid values for responsive structure: 12 columns, `70px` sections, `30px` gutters on desktop; 6 columns, `32.83px` sections, `5px` gutters on mobile.
- Apply extracted shadows only where a component requires elevation. The source contains no motion variables.
- Preserve the distinction between similarly named component variants, such as `Dropdown Top` versus `Minimal Dropdown Top`, and `Card:Event 1` versus `Card:Event 2`.
- Use the exact available decorative asset dimensions when recreating geometric or Utah-themed compositions.
