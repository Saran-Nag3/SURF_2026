# instagram - Design System

## Overview

Instagram UI Kit 1.0 is a Figma community UI kit for Instagram post and story templates. It includes reusable feed, story, navigation, profile, interaction, widget, and promotional components.

- Source page: All pages (8), including IG Post Templates, IG Stories Template, and Master Components.
- Primary screen width: 390px.
- No local variable collections found.
- Component families: Mention Widget, Countdown Widget, Slider Widget, emoji, IG slider, Question Widget, IG story user header, Carousel timer, User headers, Saved IG stories, User profile data, Tab navi bar, Story Tray, Post info, Icons, Navigation Bar, Avatar, Buttons, Quiz Widget, Question Poll Widget, IG Sponsored nav, IG message nav, Promo Banner.

## Design language

- Instagram-like interface with predominantly white surfaces, black labels and icons, circular avatars, story rings, compact navigation bars, and card-based interactive widgets.
- Primary layouts use fixed-width 390px mobile frames.
- Image and post surfaces are square or rectangular, with overlay chips and controls.
- Use gradients for Instagram-style branding, story rings, and interactive widget backgrounds.
- Typography mixes SF UI, SF Pro, Abel, Dosis, Mohave, and IBM Plex Mono depending on component context.
- Common control size: 24x24px icons and avatars.
- Common surface radii: 8px, 12px, and circular 100px treatment.

## Screen patterns

- Cover page:
  - Desktop frame: `1920x960px`.
  - Uses the IG Gradient as the full-page background.
  - White title typography includes SF UI Display Bold, 80px, and SF UI Display Regular, 32px.
  - Presents mobile feed and widget previews.

- Feed post:
  - Mobile frame width: `390px`.
  - Typical structure: top navigation, user header, square post media, post overlay details, post information, story tray, and bottom navigation.
  - Post media uses a `390x390px` square surface.
  - Carousel content can include a `3/5` chip.
  - Post info includes likes, username/caption, comment count, comment entry, reactions, and timestamp.
  - Sponsored posts can include a blue `#1FA1FF` CTA bar.

- Story tray:
  - Horizontal row of circular avatars.
  - Story avatars may show a ring and a label below.
  - Tray height: `105.75px`; story content uses `72x72px` avatar areas.

- Mobile navigation:
  - Navigation bars use 390px width and compact 24px icons.
  - Top and bottom navigation variants support light and dark mode.
  - User profile and sponsored navigation use dedicated 390px-wide variants.

- Interactive story widgets:
  - Mention, countdown, slider, question, quiz, and poll widgets use fixed card dimensions.
  - Widgets use white surfaces, rounded corners, gradients, or black/white variants.
  - Text hierarchy varies by widget and may use display fonts such as Abel, Dosis, or Mohave.

## Notes for implementers

- Keep mobile compositions at the extracted `390px` width unless a component specifies another width.
- Use the listed component dimensions as fixed dimensions; do not infer responsive values.
- Use `#FFFFFF` for the dominant surface and `#000000` for primary labels and icon treatments.
- Use `#6E6E6E` for secondary or muted text where specified by the source.
- Preserve the extracted component padding, gaps, alignment, and radius values.
- Do not replace named component variants with newly invented variants.
- Use only the documented gradients and palette colors.
- Apply shadows and blur only to the components that specify them.
- Support dark-mode variants only where explicitly listed.
- No spacing, radius, motion, or local variable collections were defined in the source; rely on the component-level values above.
