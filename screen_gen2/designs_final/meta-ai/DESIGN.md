# meta-ai - Design System

## Overview

- iOS WhatsApp interface system with chat, calls, settings, updates, search, media, and Meta AI patterns.
- Source pages: Cover, Get started, Screens, Components.
- No local variable collections found.
- Primary artboard dimensions include `393px` wide iOS layouts and `390x844px` chat backgrounds.
- Most-used styles:
  - Body 7 - Large kerining: 167 uses
  - Body 4: 154 uses
  - Balloon drop shadow: 141 uses
  - Body 2: 134 uses

## Design language

- Use SF Pro Text for most interface typography and SF Pro for selected system-style text.
- Interface hierarchy combines compact body labels with semibold section titles and large, bold screen titles.
- Chat surfaces use warm off-white backgrounds: `#F5F2EB`.
- Primary action color is green: `#1DAB61`.
- Meta AI uses a multicolor gradient:
  - `#EFA3E4` at 0%
  - `#F082D8` at 20%
  - `#036BE4` at 40–60%
  - `#65F9C2` at 82%
  - `#B5F5E2` at 100%
- Controls are predominantly rounded, with circular icon buttons, pill-shaped filters, and compact iOS navigation structures.
- Chat overlays and translucent controls use black or warm-background alpha colors.
