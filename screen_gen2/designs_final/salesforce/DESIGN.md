## Overview

- Source: Salesforce Mobile Screens Editable (Community).

## Design language

- Mobile Salesforce UI system with a broad icon library and reusable interface components.
- Typography uses Roboto for most interface styles, with Segoe UI styles for selected body and label tokens.
- Core interface colors use Salesforce blues, neutral grays, white surfaces, dark text, and explicit error and success states.
- Iconography is extensive and organized into Doctype Icons, Utility Icons, Custom Icons, Action Icons, Standard Icons, and Icon families.
- Social and brand imagery includes Instagram gradients, LinkedIn blue and white, and Behance blue.

## Notes for implementers

- Use only the listed component families; do not introduce unlisted component categories.
- Prefer named semantic colors for interface roles, especially `#0070D2` for primary actions, `#004A8A` for primary dark states, `#C23934` for errors, and `#4BCA81` / `#04844B` for success states.
- Preserve the stated typography family, weight, size, line height, and `0px` tracking for each token.
- Use `Roboto` for the primary interface type scale and `Segoe UI SegoeUI` only for the specified body and label tokens.
- Use the extracted focus effects for Button and Input focus states.
- Use the extracted border effects for container top, bottom, and combined borders.
- Do not infer spacing, corner radius, motion, grid behavior, or unspecified component dimensions; these values were not found in the source.
- Use the icon family and name appropriate to the task, retaining the extracted default size and fill where specified.
