# hulu - Design System

## Overview

- Source: Figma file “Hulu Ul Screens (Community)”, page “UIKit”.
- The extraction contains an introductory marketing screen, a before-generation showcase, and an after-generation showcase.
- No local variables, styles, components, grids, or motion tokens were found.
- The visual direction combines bright blue emphasis, dark purple supporting text, white surfaces, and very large presentation typography.

## Design language

- Use a clean, presentation-oriented editorial layout with generous whitespace.
- Primary emphasis color is blue `#4499F8`.
- Supporting dark text uses `#1F1736`; black `#000000` appears as a secondary dark neutral.
- Intro content uses Manrope with large semibold or extra-bold headings and a blue call-to-action.
- Showcase screens use dark backgrounds with white headings and large Inter labels.
- Layouts are predominantly vertical stacks with explicit gaps and large outer padding.

## Notes for implementers

- Prefer the named palette colors over arbitrary colors. Normalize near-identical white variants to `#FFFFFF` unless reproducing extracted artwork.
- Use Manrope for the intro’s expressive hierarchy and Inter for showcase labels and utility text.
- Preserve the large presentation scale: `160px` outer padding, `120px` showcase spacing, and `80px` repeated content gaps.
- Use `#4499F8` for primary emphasis and the main call-to-action; use `#1F1736` for intro supporting copy.
- The only explicitly extracted radius is `16px`; do not add other radius values.
- No reusable component families were defined. Treat extracted frames as screen-pattern references rather than established component APIs.
