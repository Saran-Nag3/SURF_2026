# linear - Design System

## Overview

- Source: Figma file “Linear Design System (Community)”.
- Pages: Cover, UI/Components, Playground.
- No local variable collections, paint styles, color variables, spacing variables, radius variables, motion variables, or grid styles were found.
- Visual system uses Inter typography, dark surfaces, neutral gray text, indigo primary actions, compact controls, rounded containers, and layered drop shadows.
- Component families: Outer container, Buttons, Issues frame, Toggle, Button, Icon, Workspace, Nav bar, Action pills, Nav bar- icons, Icons, Vectors, Action list SVG, Drop down container 3, Drop down container 2, Dropdown frame, Drop down container 1, Logo, Nav bar menu.

## Design language

- Default interface direction is dark and compact.
- Use Inter throughout the interface.
- Most-used text styles are `Label/L3/Medium` (529 uses), `Label/L4/Medium` (210), `Label/L4/Regular` (163), `Label/L5/Medium` (152), `Label/L3/Regular` (94), and `Label/L5/Regular` (76).
- Primary actions use indigo fills with lighter indigo strokes.
- Secondary and tab controls use dark gray fills with gray strokes.
- Navigation and menus use compact rounded rows with small icons and 11–13px labels.
- Status indicators use a circular form with a #F2BE00 stroke.
- Controls use subtle shadows for separation from dark surfaces.

## Screen patterns

- **Cover:** Large presentation screen introducing “Linear” and “Design System”, with the tagline “Meet the new standard for modern software development.” It also presents themes, color variables, text styles, and components.
- **UI/Components:** Component reference area containing navigation, workspaces, action pills, buttons, toggles, icons, status indicators, issues rows, and dropdown patterns.
- **Playground:** Interactive component examples using the same action pills, primary and secondary buttons, navigation icon sets, icons, and action-list status indicators.
- **Application layout:** The large application example uses a left navigation area and a main body area. Navigation contains workspace controls, icon controls, menu rows, and expandable dropdown groups. The main body contains a header/action row, filter controls, status rows, and issue content.

## Notes for implementers

- Prefer the named typography styles over raw text styles when both are available.
- Use #5E69D1 for primary action fills and #6C77E5 for their strokes.
- Use #1D1F24 with #2A2C31 for tab-like secondary controls.
- Use #23262C with #313339 for medium and large secondary buttons.
- Preserve the compact control heights: 23px, 26px, 28px, 29px, 32px, and 32.5px are all explicitly present.
- Treat hover, active, open, and expand states as component variants rather than introducing new undocumented colors or dimensions.
- Do not infer spacing, radius, motion, grid, or color variables; none were extracted.
- Use only the listed component families and concrete values from this document.
