# vercel - Design System

## Overview

Kat UI logo presentation from Page 1. The source contains three 571×222 px frame variants showing the “Kat UI” wordmark alongside a logo image.

## Design language

- Minimal logo lockup combining the “Kat UI” wordmark with a rectangular logo image.
- Wordmark uses Inter Regular at 100px.
- Variants are presented on light, black, and dark blue-black backgrounds.
- Text alignment and constraints are left/top.

## Color palette

- White: used as a frame fill and as the wordmark color on the dark blue-black frame.
- Black: used as a frame fill and as the wordmark color on the white frame.
- Dark blue-black: used as a frame fill.

## Type scale

- Inter Regular, 100px: heading treatment for the “Kat UI” wordmark.
- Wordmark text dimensions: 330×152 px.

## Screen patterns

- Light logo variant: 571×222 px frame with a white background, black “Kat UI” wordmark sized 330×152 px, and a 137×130 px logo image.
- Dark blue-black logo variant: 571×222 px frame with a dark blue-black background, white “Kat UI” wordmark sized 330×152 px, and a 137×130 px logo image.
- Image-only variant: 571×222 px frame with a black background and a 212×222 px logo image.
- All elements use left/top constraints.

## Notes for implementers

- Preserve the 571×222 px frame size for each logo presentation.
- Use Inter Regular at 100px for the “Kat UI” wordmark.
- Keep the wordmark and logo image as separate elements.
- Match the source variant backgrounds and corresponding wordmark contrast.
