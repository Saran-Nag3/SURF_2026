## Design language

- Primary typefaces in the extraction: Inter, Poppins, Open Sans, and Kodchasan.
- The Miro landing page uses a dark charcoal and warm off-white foundation, with yellow, green, blue, and purple accents.
- Promotional Web to Figma surfaces use large bold display typography, centered layouts, pill-shaped call-to-action controls, dark backgrounds, purple atmospheric effects, and white foreground text.
- Plugin interfaces use white surfaces, thin dividers, rounded containers, compact navigation, and dense content panels.
- Decorative treatments include blurred ellipses, radial gradients, background patterns, image panels, and ticker-like horizontal content.

## Notes for implementers

- Treat the listed raw typography values as observed values, not a normalized token system; no local text styles exist.
- Prefer the usage-ranked palette for defaults. Use `#000000`, `#1C1C1E`, and `#FFFFFF` most frequently, followed by `#FFDD33`, `#6C7173`, and the remaining accent colors.
- Preserve the contrast between dark charcoal sections, warm off-white page backgrounds, and bright accent sections.
- Use large pill radii for promotional call-to-action controls and smaller rounded corners for plugin shells and content cards.
- Use 16px as the only extracted icon grid specification.
- Do not assume component APIs, spacing variables, motion behavior, or effect presets; none were defined in the source.
- Decorative groups, imported images, and background patterns should remain secondary to the primary heading, supporting copy, and call-to-action.
