# nest - Design System

## Overview

Nest is a roommate-finder web app design system combining a playful, expressive visual direction with practical dashboard and empty-state patterns.

- Source pages: Moodboard, Experiment, Nest.
- Primary product UI uses purple, orange, white, and neutral slate tones.
- Desktop layouts include 1440px-wide navigation, footer, and dashboard patterns.
- A 12-column grid is specified with 87.33px sections and 24px gutters.
- No local variable collections, text styles, spacing variables, radius variables, or motion variables were found.

## Design language

- Expressive and friendly, using vivid purple and orange accents.
- Display typography uses Sedan and Waiting for the Sunrise.
- Interface typography primarily uses Montserrat and Poppins.
- White surfaces and light neutral backgrounds provide contrast for saturated accents.
- Roommate-finder UI includes profile cards, match indicators, heart controls, navigation, and empty states.
- Moodboard material also shows hand-written and editorial typography, colorful imagery, organic decorative shapes, and rounded forms.

## Screen patterns

- **Roommate-finder experience:** profile-oriented cards and controls using `303px` card widths, white surfaces, match percentage labels, named profile labels, heart controls, and circular elements.
- **Desktop navigation:** a `1440×120px` navigation bar using Montserrat for interface labels and Waiting for the Sunrise for expressive branding.
- **Desktop footer:** a `1440×340px` footer with compact Montserrat text and expressive branding typography.
- **Dashboard shell:** `1440×927px` layouts with a light sidebar, top header, search field, profile/admin information, notifications, and navigation items.
- **Search empty state:** dashboard search result page with “no results” messaging, an empty-state illustration, and a back-to-dashboard button.
- **Chat empty state:** dashboard shell with sidebar navigation and a no-chat content state.
- **Moodboard compositions:** colorful imagery, decorative vectors, circular image masks, large editorial headings, and product-poster layouts.
- **Responsive moodboard variant:** the same composition appears at `1012×506px` and `446×356px`, with reduced type and group dimensions.

## Notes for implementers

- Use `#9F12E0` as the primary brand accent and `#FF4500` as the secondary accent.
- Prefer `#FFFFFF` for cards, controls, and primary surfaces; use `#F7F7F7`, `#F8FAFC`, or `#F1F5F9` for light backgrounds where appropriate.
- Use `#331A56` for prominent product text and `#5F5E62` or `#888888` for body and secondary text.
- Use Montserrat and Poppins for interface content. Reserve Sedan and Waiting for the Sunrise for expressive display or brand text.
- Match the source’s desktop proportions when implementing navigation, footer, and dashboard shells.
- Use the specified component sizes rather than introducing new dimensions.
- Do not infer additional tokens: the source contains no spacing, radius, motion, or local text-style variables.
- Use only the listed component families and source colors when recreating the system.
